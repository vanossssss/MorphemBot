# Morphem Bot
Бот - учебный проект, позволяет разбирать слова на морфемы. 
## Как работает
Пользователь пишет соответвующую команду и слово, отправляется запрос на сайт с разборами. Далее с html-страницы сайта с помощью библиотеки jsoup парсятся морфемы слова.
# Как пользоваться
При первом заходе в диалог необходимо ввести команду /start.
Далее с помощью /parse и дальнейшего ввода слова, бот выводит данные по введённому слову.
Отменить команду /parse можно с помощью команды /cancel.
